# AGENTS.md

Общие правила работы с репозиторием. Вложенные файлы могут дополнять эти инструкции.

## Структура
- `app/api` — FastAPI маршруты
- `app/config` — настройки и клиенты
- `app/core` — инфраструктура и вспомогательные функции
- `app/models` — ORM модели
- `app/schemas` — Pydantic модели
- `app/utils` — утилиты
- `app/migrations` — alembic миграции
- `app/tests` — тесты
- `docs/` — документация
- точка входа: `app/main.py`

## Код-стайл
- PEP8 + типы, форматирование `black`, линтер `flake8`
- Используйте f-строки
- В `Field()` указывайте `description`

## Локальный запуск
Используйте `make up` и `make down`. Подробнее в документации.

## Тесты
- `pytest -q` (интеграционные тесты запускаются с `--runintegration`)
- Каждый тест должен содержать докстринг с описанием проверяемого поведения.

## Pull request
- Краткий глагол в заголовке
- Описание содержит `## Summary` и `## Testing`

## Проверки перед коммитом
- Выполняйте `pre-commit run --all-files`.

### Неиспользуемый код
- `vulture app vulture_whitelist.py` запускается в прекоммите. Если в выводе найдены функции или переменные, подтвердите каждую строку и опишите результат в PR.
